# Smart Campus Management Platform

A web-based Smart Campus Management Platform that connects students and faculty through a centralized campus management system.

## 🚀 Features

### Student
- Student registration and login
- Registration-number based authentication
- Student dashboard
- View campus events
- View announcements
- Submit complaints
- Track complaint status
- Report lost and found items
- View submitted lost and found reports

### Faculty
- Faculty registration and login
- Faculty dashboard
- View and manage student complaints
- Update complaint status
- View and manage lost and found reports
- Update lost and found status
- Create campus events
- View campus events
- Create announcements
- View announcements

## 🔐 Authentication

The platform uses:

- Registration Number
- Password
- JWT authentication
- Protected routes
- Role-based access control

There are two roles:

- Student
- Faculty

Faculty manages the campus activities and student submissions. No separate Admin role is required.

## 🛠️ Technology Stack

### Frontend
- React
- React Router
- Tailwind CSS
- Lucide React

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
